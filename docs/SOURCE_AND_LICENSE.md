# Исходники, происхождение и лицензия

## База исходного кода

Прошивка собрана из пользовательского порта:

- репозиторий: <https://github.com/Jafarabat2025/AP>;
- коммит: `221251fa69896d8f0d3ecb4d7b0bc6901bbd2074`;
- автор исходного коммита порта: Jafarabat2025;
- основа проекта: <https://github.com/ArduPilot/ardupilot>.

Аппаратное описание HAKRCF405V2 находится в:

```text
libraries/AP_HAL_ChibiOS/hwdef/HAKRCF405V2/hwdef.dat
libraries/AP_HAL_ChibiOS/hwdef/HAKRCF405V2/hwdef-bl.dat
```

Публикационный коммит добавляет русскую документацию, оформление и инструкции.
Исходный код проверенной прошивки относительно указанного коммита не изменён.

## Подмодули

ArduPilot использует зафиксированные Git-подмодули, включая ChibiOS, Waf,
MAVLink и DroneCAN. Получайте их командой:

```bash
git submodule update --init --recursive
```

Точные URL и коммиты задаются файлами `.gitmodules` и gitlink-записями
репозитория.
