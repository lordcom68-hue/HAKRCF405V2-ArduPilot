# Аппаратная цель HAKRCF405V2

Источник истины — файлы `hwdef.dat` и `hwdef-bl.dat` в каталоге
`libraries/AP_HAL_ChibiOS/hwdef/HAKRCF405V2`.

## Основные параметры

| Параметр | Значение |
|---|---|
| MCU | STM32F405xx |
| Flash | 1024 КБ |
| Частота кварца | 8 МГц |
| Board ID | 4202 (`AP_HW_HAKRCF405V2`) |
| Резерв загрузчика и хранилища | 64 КБ в начале Flash |
| Размер параметров | 15 360 байт |
| USB | OTG FS |

## Датчики и периферия

- IMU: ICM42688/совместимый Invensense v3 по SPI;
- ориентация IMU: `ROTATION_ROLL_180_YAW_90`;
- барометр: DPS310 по I²C, допускается ревизия платы без встроенного барометра;
- встроенного компаса нет, поддерживается внешний компас по I²C;
- OSD: MAX7456;
- журналирование: внешняя DataFlash;
- отдельные входы контроля напряжения, тока и аналогового RSSI;
- синий и зелёный светодиоды, а также буззер.

## Последовательные интерфейсы

Логический порядок ArduPilot:

```text
USB, USART1, USART2, USART3, UART4, UART5, USART6
```

USART2 используется как один из вариантов подключения RC/SBUS. Для внешней
телеметрии применяйте полноценную пару `TX/RX` одного UART. Не объединяйте RX
одного UART с TX другого.

## PWM-выходы

Аппаратная цель объявляет девять выходов `PWM(1)`–`PWM(9)` на таймерах TIM8,
TIM1, TIM3 и TIM2. Нумерация следует соглашениям ArduPilot, но фактический
порядок моторов необходимо проверить на вашей разводке платы без пропеллеров.

## Возможные отличия ревизий

У плат с одинаковым коммерческим названием могут отличаться:

- наличие и адрес барометра;
- номиналы делителей измерения аккумулятора;
- распиновка разъёмов и подписи на корпусе;
- тип внешней Flash и разводка OSD;
- ориентация IMU.

Если горизонт, датчики или моторные выходы работают неправильно, не пытайтесь
компенсировать неизвестную аппаратную ревизию случайными параметрами. Сначала
сверьте маркировку компонентов и схему платы с `hwdef.dat`.
